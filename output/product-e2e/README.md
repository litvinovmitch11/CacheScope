# Готовый отчёт CacheScope

Откройте **[report.html](report.html)** двойным щелчком в браузере.
Если скачиваете файл через GitHub, используйте **Download raw file**:
GitHub показывает исходный HTML, а не запускает его.

Для просмотра не нужны Docker, LLVM, Node.js, backend или интернет.
Интерфейс и данные уже встроены в один HTML-файл. Его можно переслать отдельно
от остальной папки.

## Что показывает пример

Это результат канонического [matmul 16×16 f32](../../examples/workloads/matmul.mlir)
для трёх порядков обхода: `baseline`, `tile4` и `tile4-ikj`.
Входные матрицы A и B заполнены единицами, C — нулями; каждый запуск
проверен по результату `C[0, 0] == 16`. Во всех трассах 16 384 события.

Модель L1: 512 B, строка 64 B, direct-mapped, LRU, write-back, write-allocate.
Маленький учебный кэш делает различия порядков обращений видимыми;
это не измерение скорости реального CPU.

| Вариант | Cache hits | Cache misses | Hit rate |
|---|---:|---:|---:|
| `baseline` | 4 096 | 12 288 | 25.00% |
| `tile4` | 7 360 | 9 024 | 44.92% |
| `tile4-ikj` | 7 504 | 8 880 | 45.80% |

В HTML доступны сравнение вариантов, подробные счётчики и раскрывающаяся
таблица «Инструкции (4)» для каждой карточки. Текстовая сводка с дельтами —
[RESULTS.md](RESULTS.md).

## Что лежит в папке

```text
product-e2e/
├── report.html                     # автономный UI с данными
├── RESULTS.md                      # сводка и дельты
├── summary.json                    # три варианта и различия трасс
├── baseline/                       # MLIR-стадии и полный trace.json
├── tile4/                          # MLIR-стадии и полный trace.json
├── tile4-ikj/                      # MLIR-стадии и полный trace.json
└── simulation/
    ├── baseline-l1/                # statistics.json и events.json
    ├── tile4-l1/                   # statistics.json и events.json
    └── tile4-ikj-l1/               # statistics.json и events.json
```

Файлы `trace.json` полные, без усечения. `events.json` содержит результат
каждого обращения; MLIR-стадии сохранены для проверки source mapping.

Папку можно также импортировать в уже открытый CacheScope UI кнопкой
«Выбрать папку output/<experiment>/»: выбирайте **эту папку `product-e2e`**,
а не её родительскую `output`.

## Как воспроизвести

Снимок подготовлен 2026-11-11 из `main` (`f151e9c`) с LLVM/MLIR 22.1.8.
Генератор выполнил программу, проверил трассы, прогнал их через runner
и собрал HTML штатным `ui/scripts/make-report.mjs`.

При наличии [зависимостей для генерации](../../examples/product-e2e/README.md)
в корне репозитория выполните:

```bash
python3 examples/product-e2e/run.py
```

В сохранённых `04-llvm.mlir` и `05-executable.mlir` удалены завершающие
пробелы и пустая строка в конце файла, которые печатает MLIR.

Команда заново создаст эту директорию и HTML. Для просмотра готового снимка
перегенерация не требуется.
